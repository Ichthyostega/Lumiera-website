Real-World implementations
~~~~~~~~~~~~~~~~~~~~~~~~~~
 - *VLC* link:https://code.videolan.org/videolan/vlc/-/tree/master/modules/video_output[Video output modules]
 - In *GStreamer*, the link:https://github.com/GStreamer/gst-plugins-base/blob/master/ext/gl/gstglimagesink.c[gst_gl_imagesink]
   handles the OpenGL based display of video frames; however -- as can be expected by such a massive framework --
   it is near impossible to derive any conclusions regarding actual implementation technique from this code;
   all you can get hold off are GStreamer internal types, messages and wiring.
 - the video monitor *xjadeo* from Robin Gareus implements various
   link:https://github.com/x42/xjadeo/blob/master/src/xjadeo/display.c[Video display back-ends];
   while this code is _very old,_ it is easy to follow and allows to identify actual graphics implementation routines.

OpenGL
~~~~~~

 * The link:https://en.wikipedia.org/wiki/Khronos_Group[»Khronos Group«] is a non-profit consortium
   and maintains the stewardship for the OpenGL specifications.
 * link:https://www.khronos.org/opengl/wiki/Programming_OpenGL_in_Linux:_GLX_and_Xlib[Khronos Wiki: Programming OpenGL in Linux (2014)]
 * link:https://www.khronos.org/opengl/wiki/Platform_specifics:_Linux[Khronos: Platform specifics -- Linux (2021)]
 * GLX is an X-Lib extension, which allows to bind an OpenGL context to an X11 based display.

   ** link:https://en.wikipedia.org/wiki/GLX[Wikipedia: GLX]
   ** link:https://registry.khronos.org/OpenGL/specs/gl/glx1.4.pdf[GLX 1.4 Reference (PDF)]
   ** GLX is also documented as part of the link:https://registry.khronos.org/OpenGL-Refpages/gl2.1/[Legacy API v2.x]
   
 * EGL is a modern cross-platform integration library for OpenGL or OpenGL ES (GLES) or OpenVG
 
   ** link:https://en.wikipedia.org/wiki/EGL_(API)[Wikipedia: EGL]
   ** link:https://www.khronos.org/egl/[Khronos: Overview EGL]
   ** link:https://registry.khronos.org/EGL/sdk/docs/man/[EGL API doc]
 
 * to find out about the OpenGL API level supported on your system
+
----
glxinfo | grep "OpenGL version"
----
+
 * API Reference:
   link:https://registry.khronos.org/OpenGL/index_gl.php[current Core-API] ·
   link:https://registry.khronos.org/OpenGL-Refpages/gl4/[OpenGL 4.x (core)] ·
   link:https://registry.khronos.org/OpenGL-Refpages/gl2.1/[Legacy & GLX-API]
