Development Version
-------------------

Lumiera is currently under active development. +
We are in a pre-alpha stage, meaning that the software is *not usable yet*.

However, we have an early GUI draft in place which might give a feel
for what the interface could look like.  It is available for end-user
experimentation now, but usually you need to _build_ it first.

Lumiera Debian package
~~~~~~~~~~~~~~~~~~~~~~
Some of the Lumiera core developers use Debian/stable (**Trixie**) as a reference system
for development. This has the pleasant side effect of allowing us to provide Debian
packages to reflect ongoing development. Since Ubuntu is based on Debian,
we provide packaging for some Ubuntu distributions as well.

While Lumiera does not yet offer any usable features, it can already
be installed via Debian packaging mechanisms. We prepare pre-releases
and build packages in containers to rehearse the release mechanisms.
Thus, if you happen to use a Debian/stable based system _(Doh!)_,
or a suitable flavour of Ubutu, you might be able to try out our
link:/debian[DEB depot] for the Apt package manager of Debian.
Please be sure to report any broken dependencies and installation problems.
