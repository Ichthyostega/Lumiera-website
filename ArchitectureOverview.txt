</p><h1 id="head-fb2c0de3e40cc43fd4b41d9190d859e0a8a781c1">Architecure Overview</h1>

<p></p>
<p>envisioned Architecture of the Application </p>
<p><img class="attachment" src="ArchitectureOverview_files/ArchitectureOverview.png" title="attachment:Cin3.Architecture-1.png"> </p>
<p>
</p><h2 id="head-298af965641f70cdfd88f111c32fc74749be74f7">Description</h2>

<p></p><ul>
<li>the Application has three Layers: Backend, Proc and GUI </li>
<li>the Application shall be completely functional without GUI (script-driven) </li>
<li>all IO, media data fetching, processing and bookkeeping falls within the realm of the Backend </li>
<li>all media object manipulation, deciding and configuration is the Proc Layer's job </li>
<li>extendible by plugins on all levels, highly configurable, but not totally componentized (micro kernel) architecture </li>
<li>strong separation between high-level and low-level areas of the Application </li>
<li>the user/GUI manipulates a high-level model wheras rendering is based on a corresponding low-level model </li>
<li>stored Session (state) is comprised of hig-level model, a collection of Assets and accompaning configuration </li>
<li>(possibly) several storage backends, abstracted out by a common interface </li></ul>
