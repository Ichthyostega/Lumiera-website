</p><h1 id="head-fb2c0de3e40cc43fd4b41d9190d859e0a8a781c1">Architecure Overview</h1>
<span class="anchor" id="line-12"></span><p class="line867"><span class="anchor" id="line-13"></span></p><p class="line874">envisioned Architecture of the Application <span class="anchor" id="line-14"></span><span class="anchor" id="line-15"></span></p><p class="line867"><img class="attachment" src="ArchitectureOverview_files/ArchitectureOverview.png" title="attachment:Cin3.Architecture-1.png"> <span class="anchor" id="line-16"></span><span class="anchor" id="line-17"></span><span class="anchor" id="line-18"></span></p><p class="line867">
</p><h2 id="head-298af965641f70cdfd88f111c32fc74749be74f7">Description</h2>
<span class="anchor" id="line-19"></span><p class="line867"><span class="anchor" id="line-20"></span></p><ul><li>the Application has three Layers: Backend, Proc and GUI <span class="anchor" id="line-21"></span></li><li>the Application shall be completely functional without GUI (script-driven) <span class="anchor" id="line-22"></span></li><li>all IO, media data fetching, processing and bookkeeping falls within the realm of the Backend <span class="anchor" id="line-23"></span></li><li>all media object manipulation, deciding and configuration is the Proc Layer's job <span class="anchor" id="line-24"></span></li><li>extendible by plugins on all levels, highly configurable, but not totally componentized (micro kernel) architecture <span class="anchor" id="line-25"></span></li><li>strong separation between high-level and low-level areas of the Application <span class="anchor" id="line-26"></span></li><li>the user/GUI manipulates a high-level model wheras rendering is based on a corresponding low-level model <span class="anchor" id="line-27"></span></li><li>stored Session (state) is comprised of hig-level model, a collection of Assets and accompaning configuration <span class="anchor" id="line-28"></span></li><li>(possibly) several storage backends, abstracted out by a common interface <span class="anchor" id="line-29"></span><span class="anchor" id="line-30"></span><span class="anchor" id="line-31"></span></li></ul><p class="line867">
